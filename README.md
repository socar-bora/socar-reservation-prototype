# 쏘카 웹 예약 프로토타입

쏘카존·배달 예약 흐름과 위치 바 인터랙션을 확인하는 공개 프로토타입입니다.

- [프로토타입 열기](https://socar-bora.github.io/socar-reservation-prototype/)
- [위치 바 모션 비교](https://socar-bora.github.io/socar-reservation-prototype/?motion=slide)

모션 비교 화면에서 버퍼 타임(0~1,000ms), 등장 속도, 가속 방식, 회전 강도를 각각 바꾸고 반복 재생할 수 있습니다.

위치 바 기본값: 300ms 대기 후 위에서 내려오기 / 등장 840ms / Ease-out / 회전 없음.

실제 예약·결제나 실시간 차량 조회는 진행되지 않습니다. 지도·차량·요금은 시연용 데이터입니다.

## 배포

`main` 브랜치의 루트 폴더를 GitHub Pages로 배포합니다. `index.html`과 `socar-zone-delivery-switch.html`은 동일한 내용으로 유지합니다.
